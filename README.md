# PingReply

Website and privacy policy for the **PingReply** Android app — auto-reply to missed calls with SMS.

## Pages

- **[Home](https://neatbuilds.github.io/ping-reply)** — App landing page, features, permissions, privacy statement
- **[Privacy Policy](https://neatbuilds.github.io/ping-reply/privacy)** — Full Data Protection Notice (GDPR-compliant)

## Built with

- **Pure HTML5 + CSS3** — No frameworks, no dependencies
- **JavaScript (vanilla)** — Reveal on scroll, nav state detection
- **Hosted on GitHub Pages** — Fast, secure, free

## Design System

- **Theme:** Dark mode with orange accent (#FF6B2B)
- **Typography:** Space Grotesk (headings) + DM Sans (body)
- **Animations:** Smooth reveal on scroll, hover effects
- **Responsive:** Mobile-first, fully responsive

## Development

No build step needed. Just edit `.html` files directly:

- `index.html` — Landing page
- `privacy.html` — Privacy policy

Push to GitHub and it deploys automatically to GitHub Pages.
